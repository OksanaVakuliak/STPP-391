# Royal Journey

Landing page for the mobile game Royal Journey — a match-3 adventure where King William travels the world and clears levels in iconic cities.

Domain: rapidbanner.space

Built with HTML, CSS and JavaScript, bundled with Vite.

## Pages

- `index.html` — home page: Hero, About the Game, How to Play, Features, FAQ, Contact
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service

## Getting started

Install dependencies:

```bash
npm install
```

Run locally (opens at http://localhost:5173):

```bash
npm run dev
```

Build for production into the `dist` folder:

```bash
npm run build
```
